# Drochibelno Li?

`Drochibelno Li?` or `Дрочибельно ли?` - this is a Telegram bot on aiogram that estimates how much you can masturbate to each photo, video, sticker, GIF, and file that is sent to the group.
Currently available only in Russian.
Licensed under MIT.

Official bot: https://t.me/drochibelno_li_bot

## Installing

1. Clone the repository:
```bash
git clone https://codeberg.org/m1lkydev/drochibelno_li
cd drochibelno_li
```

2. Install the libraries:
```bash
pip install aiogram aiohttp-socks python-dotenv
```

3. Edit the settings in .env

4. Run the main.py:
```bash
python3 ./main.py # or py .\main.py for Windows
```
